# Yalivox

**Find entry-level remote jobs. Apply directly.**

Yalivox helps students, recent graduates and career changers find remote work and apply well.

- **Remote internships and early-career roles** taken directly from employers' career pages on Greenhouse, Lever, Ashby, Recruitee and SmartRecruiters, refreshed every 6 hours. Hybrid and on-site roles are removed, and each job shows the region it hires from.
- **Free ATS resume checker**, no sign-up: compare your resume with a job description and see missing keywords and formatting problems.
- **Apply on the employer's own site.** Yalivox never submits applications for you.
